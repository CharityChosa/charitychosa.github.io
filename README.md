# Charity Chosa portfolio

A lightweight personal portfolio built with plain HTML and CSS. The page contains only the portfolio content; the source CV is not included.

## Preview on your computer

1. Open Terminal.
2. Run `cd ~/Desktop/Github/charitychosa.github.io` to open this website's folder.
3. Run `python3 -m http.server 8000` to start a small local web server.
4. Open <http://localhost:8000> in your browser.
5. When you finish previewing, return to Terminal and press Control+C to stop the server.

You can edit the page text in `index.html` and its appearance in `styles.css`. The CSS comments label the main page sections.
